# 3.7 模块六：UI 基础设施与国际化

## 3.7.1 模块概述
本模块为 fitness 应用提供底层 UI 基础设施支撑，涵盖国际化(i18n)、主题管理、全局导航、截图工具链及 UI 组件库。采用 **Next.js App Router + next-intl + next-themes + shadcn/ui** 技术栈，构建支持多语言、多主题、高可访问性的现代化 Web 应用界面。

**核心职责**：
- 提供中英双语国际化支持，实现无缝语言切换
- 管理亮色/暗色主题切换及系统主题适配
- 构建全局导航与布局框架
- 实现复杂的 DOM 截图功能（用于健康报告分享）
- 维护可复用的 UI 组件库与全局样式系统

## 3.7.4 核心组件详细设计
### 3.7.4.1 根布局 (`app/[locale]/layout.tsx`)
**职责**：作为所有页面的根布局，组合国际化、主题、导航和通知系统。

**设计要点**：
- **动态路由参数**：使用 `[locale]` 动态段实现语言路由（如 `/zh/dashboard`, `/en/dashboard`）
- **翻译文件加载**：根据 locale 参数异步加载对应语言的 JSON 文件
- **Provider 嵌套顺序**：`NextIntlClientProvider` → `ThemeProvider` → `MainNav` + `Toaster`
- **元数据配置**：动态生成页面标题和描述，支持多语言 SEO

**关键代码结构**：
```typescript
// 生成静态参数，支持中英文
export function generateStaticParams() {
  return [{ locale: 'zh' }, { locale: 'en' }];
}

// 根布局组件
export default async function LocaleLayout({
  children,
  params: { locale }
}: Props) {
  const messages = (await import(`@/messages/${locale}.json`)).default;
  
  return (
    <html lang={locale} suppressHydrationWarning>
      <body className={inter.className}>
        <NextIntlClientProvider messages={messages} locale={locale}>
          <ThemeProvider attribute="class" defaultTheme="system" enableSystem>
            <MainNav />
            <main>{children}</main>
            <Toaster />
          </ThemeProvider>
        </NextIntlClientProvider>
      </body>
    </html>
  );
}
```

### 3.7.4.2 导航栏 (`components/main-nav.tsx`)
**职责**：提供全局导航、品牌展示、语言切换、主题切换及 GitHub Star 统计。

**设计要点**：
- Sticky 定位：`sticky top-0 z-50`，始终可见
- 毛玻璃效果：`backdrop-blur-md bg-background/80`，现代视觉体验
- 路由高亮：使用 `usePathname()` 检测当前路由，应用激活样式
- 响应式设计：移动端使用汉堡菜单，桌面端水平导航
- GitHub Star：实时获取仓库 Star 数并显示

**关键交互**：
- 语言切换：调用 `useRouter()` 和 `usePathname()` 实现无刷新语言切换
- 主题切换：调用 `setTheme()` 在 light/dark/system 间切换
- 移动端菜单：使用 `useState` 管理菜单展开/收起状态

### 3.7.4.3 国际化中间件 (`middleware.ts`)
**职责**：基于 next-intl 实现路由级别的国际化处理。

**设计要点**：
- 路径匹配：使用 `createMiddleware` 配置匹配路径
- 语言检测：自动检测用户浏览器语言偏好
- 路由重写：无 locale 前缀的请求自动重定向（如 `/` → `/zh`）
- Cookie 记忆：记住用户语言选择，下次访问自动应用

**配置参数**：
```typescript
export default createMiddleware({
  locales: ['zh', 'en'],      // 支持的语言列表
  defaultLocale: 'zh',         // 默认语言
  localeDetection: true,       // 启用浏览器语言检测
  localePrefix: 'always'       // 始终显示语言前缀
});
```

**职责**：封装 next-themes，为应用提供主题管理上下文。

## 3.7.5 截图功能详细设计
### 3.7.5.1 截图工具库 (`lib/screenshot-utils.ts`)
**职责**：封装 3 种截图方案，提供统一接口并支持智能降级。

**三种方案对比**：
| 方案 | 原理 | 优点 | 缺点 | 适用场景 |
|------|------|------|------|----------|
| html2canvas | 将 DOM 解析为 Canvas | 兼容性好，可自定义样式 | 复杂样式可能失真 | 主要方案，用于 Summary 页 |
| 原生 Screen Capture | 调用浏览器原生 API | 质量高，速度快 | 需要用户授权，兼容性差 | 降级方案 |
| SVG 转换 | 将 DOM 序列化为 SVG | 矢量无损，文件小 | 动态内容支持差 | 特殊场景 |

**智能降级策略**：
1. 优先尝试 html2canvas（最稳定）
2. 若失败且浏览器支持，尝试 原生 Screen Capture API
3. 若均失败，返回错误提示，引导用户手动截图

**核心函数签名**：
```typescript
// 主截图函数
export async function captureElement(
  element: HTMLElement, 
  options?: ScreenshotOptions
): Promise<Blob>

// DOM 预处理（用于 html2canvas 前）
export function preprocessForScreenshot(element: HTMLElement): void

// 样式修复（解决截图时的样式偏移问题）
export function fixStylesForScreenshot(clone: HTMLElement): void
```

### 3.7.5.2 每日汇总页截图 (`app/[locale]/summary/page.tsx`)
**职责**：展示用户每日健康数据汇总，并提供一键截图分享功能。

**截图流程**：
1. DOM 预处理：
   - 展开所有 `Collapsible` 组件，确保内容完整
   - 修复 `Badge` 组件的位置偏移
   - 优化容器宽度，避免截图截断
2. 样式注入：将当前页面的所有 CSS 规则克隆到截图容器中
3. 暗色主题适配：检测当前主题，确保截图与显示效果一致
4. 高分辨率输出：设置 `scale: 2` 生成 2x 分辨率图片，保证清晰度
5. 下载触发：生成 Blob URL，触发浏览器下载

**关键实现细节**：
- 使用 `useRef` 获取截图目标 DOM 元素
- 截图前临时修改样式（如移除滚动条、固定宽度）
- 截图完成后恢复原始样式
- 支持生成 PNG 和 JPEG 格式

## 3.7.6 全局样式系统 (`app/globals.css`)
**职责**：定义设计令牌、CSS 变量、自定义动画及 Tailwind 基础指令。

**核心内容**：
1. CSS 变量定义（亮色/暗色主题）
```css
:root {
  --background: 0 0% 100%;
  --foreground: 240 10% 3.9%;
  --primary: 142 76% 36%;      /* 健康主题绿色 */
  --primary-foreground: 0 0% 100%;
  /* ... 其他变量 */
}

.dark {
  --background: 240 10% 3.9%;
  --foreground: 0 0% 98%;
  /* ... 暗色覆盖 */
}
```

2. 自定义动画 Keyframes
- `breathing`：呼吸动画，用于冥想/放松提示
- `float`：悬浮动画，用于卡片悬停效果
- `glow`：发光动画，用于强调元素
- `bounce-slow`：缓慢弹跳，用于通知提示

3. 健康主题色系
- 主色：绿色系（#22c55e），象征健康与活力
- 辅助色：蓝色系（信息）、橙色系（警告）、红色系（危险）
- 中性色：灰色系（背景、边框、文字）

4. Tailwind 基础指令
- `@tailwind base`：重置样式
- `@tailwind components`：组件层
- `@tailwind utilities`：工具类

## 3.7.12 风险与注意事项
1. 截图性能：Summary 页内容较多时，html2canvas 生成时间可能较长（>2s），需添加加载状态提示
2. 样式一致性：暗色主题下截图需确保所有元素颜色正确，建议截图前强制应用当前主题样式
3. 翻译维护：新增功能时需同步更新 zh.json 和 en.json，建议建立翻译检查清单
4. 主题闪烁：首次加载时可能出现主题闪烁，需确保 `suppressHydrationWarning` 正确配置
5. 移动端适配：导航栏在移动端需测试触摸交互，确保下拉菜单和主题切换正常

## 3.7.13 测试策略
- 国际化测试：验证语言切换后所有文本正确更新，路由前缀正确变化
- 主题测试：验证亮色/暗色/系统主题切换正常，无闪烁
- 截图测试：验证不同内容长度、不同主题下的截图质量
- 响应式测试：验证导航栏在 320px-1920px 宽度范围内正常显示
- 无障碍测试：验证所有交互元素可通过键盘访问，ARIA 标签正确
